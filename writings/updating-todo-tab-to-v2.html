    • Updating Todo Tab to v2.0.0

    03 Dec 2017

    I'm so happy to announce a new version of Todo Tab released on 27th November with more productivity helpers.

    What's new? 🎉

    1. One of the most awaited and requested feature, the ability to create and manage custom colour codes

    2. You can reorder your task list as you wish
    3. If you made a typo mistake while adding the task, now you can edit the description, no more delete and re-entering
    4. Shows the remaining task count in tab title
    5. If you have more than two completed task, todo tab will hide the rest and keep the todo list always small
    6. Made URLs shorten and clickable in the task description
    7. If you have more than five completed task, todo tab will give you the option to clear all completed task in one go

    Technical Update

    Introduced React JS to write UI components faster and speed up prototyping.

    *     *     *
    Get Extension

    The extension is currently available only for Chrome. But no worries, all other platforms including mobile are on the roadmap.
